NYU Space Talks Website Migration

Website Migration and Redesign

Type
Web migration
Role
Lead developer
Stack
Next.js, React, TypeScript, Tailwind CSS, Vercel, Supabase

Modernizing a public event archive

I am leading the migration of the NYU Space Talks website from Wix to a custom-built web application. The project is focused on modernizing the visual design, improving the organization of a growing event archive, reducing platform limitations, and creating a more flexible foundation for future features.

Key Work

  • Auditing and restructuring existing Wix content, including event information, speakers, recordings, images, and external links
  • Rebuilding the frontend with reusable Next.js, React, TypeScript, and Tailwind CSS components
  • Designing responsive layouts for clearer navigation and easier access to past talks
  • Planning newsletter registration, Zoom RSVP links, and contact forms for community engagement
  • Preparing deployment on Vercel with domain configuration, redirects, responsive testing, accessibility checks, and performance optimization

My Role

My role includes web development, information architecture, UI/UX redesign, content migration, and deployment planning. Future phases may introduce Supabase for user accounts, community features, and archive search and filtering.

Technologies

Next.js, React, TypeScript, Tailwind CSS, Vercel, and Supabase.
