Airline Reservation System

Databases Project

Timeline
Sep 2025 - Dec 2025
Type
Full-stack database app
Stack
Flask, MySQL, JavaScript

A reservation platform with real database workflows

This project is a full-stack airline reservation system with booking workflows, authentication, analytics dashboards, and role-based access control. I designed the application around three user groups: customers, airline staff, and administrators.

Key Work

  • Built booking workflows for searching, reserving, and managing flights
  • Designed relational database structures and role-based user flows
  • Created analytics dashboards and reporting tools with database queries and JSON APIs
  • Implemented password hashing, session authentication, and role-based access control
