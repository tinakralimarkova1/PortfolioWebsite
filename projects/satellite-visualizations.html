Research Assistant Work

Timeline
Dec 2025 - Present
Type

Stack
Python, Plotly.js, HTML/CSS, Vercel

Visual tools for historical satellite research

This work supports a historical satellite database of more than 60,000 orbital and payload records. I built data processing workflows and interactive web-based visualizations so researchers can explore large historical satellite datasets and translate research questions into visual analytics.

Key Work

  • Integrated, validated, and standardized satellite data from multiple catalogs and research sources
  • Developed interactive data visualizations with JavaScript, Plotly.js, HTML/CSS, and Git
  • Migrated the project website from Wix to a custom Vercel-hosted platform
  • Partnered with historians to turn research questions into data-driven visual tools
