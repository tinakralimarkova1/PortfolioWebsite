Hydrachnid

Robotics Project

Timeline
Jan 2026 - Present
Type
Hydraulic quadruped robot
Stack
Arduino, C/C++, motors, valves

A spider-inspired robot powered by hydraulics

Hydrachnid is a spider-inspired quadruped robot designed around hydraulic actuation and centralized power distribution. The project explores how motors, valves, syringes, and elastic return mechanisms can reduce mechanical complexity while still supporting pressure-driven locomotion.

Key Work

  • Designed and built a spider-inspired quadruped robot using hydraulic actuation
  • Programmed an Arduino Uno in C/C++ to control motors, valves, and locomotion behavior
  • Integrated motors, valves, syringes, and elastic return mechanisms into a working system
  • Used centralized power distribution to simplify the robot architecture
