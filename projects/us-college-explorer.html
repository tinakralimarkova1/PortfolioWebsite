Timeline
Sep 2025 - Dec 2025
Type
Interactive dashboard
Stack
Next.js, Python, GeoJSON

Exploring colleges through data and maps

US College Explorer is an interactive dashboard for comparing institutions by admissions selectivity, tuition, enrollment, campus size, location, SAT scores, and cost metrics. The project focused on making a large education dataset easier to filter, compare, and understand visually.

Key Work

  • Processed and transformed educational datasets with Python before integrating them into the app
  • Built dynamic filters for admissions, tuition, enrollment, location, and cost metrics
  • Implemented interactive charts and GeoJSON-based geographic visualizations
  • Designed a responsive interface for comparing colleges across multiple dimensions
